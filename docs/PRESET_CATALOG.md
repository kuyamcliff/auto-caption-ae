# CyriqCap preset catalog

Built from a frame-by-frame study of 7 reference videos (text-pack showcases and
tutorials). Duplicates across videos were merged. Every preset is an original
re-implementation of the *technique* (animators, timing, effects, colours, font
style) — no project files, artwork, footage or branding from those videos are
used. Preset names are CyriqCap's own.

Fonts are all SIL Open Font License families bundled with the extension.

Legend for "Needs": `—` built-in After Effects only. Plugin names mean the preset
will refuse to apply (with a clear message) when that plugin is not installed.
